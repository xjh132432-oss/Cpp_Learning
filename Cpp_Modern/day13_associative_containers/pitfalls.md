# Day13 Pitfalls：关联式容器

## 1. map 的 operator[] 会自动插入元素

使用：

    students[5]

当 Key 为 5 的元素不存在时，`operator[]` 会自动创建该元素，并对 Value 进行默认初始化。

因此，访问不存在的学号后，原本没有的元素也会出现在后续遍历结果中。

如果只想查找而不希望插入，应使用 `find()`。

## 2. find() 的返回值需要使用

直接调用：

    student.find(3);

虽然执行了查找，但没有使用返回结果。

正确做法是接收迭代器，并与 `end()` 比较：

    auto it = student.find(3);

    if (it != student.end())
    {
        // 找到元素
    }

## 3. 整数前导零不是字符串前导零

整数写法 `01` 表示八进制整数，数值等于十进制的 1。

如果学号需要保留 `01` 这样的格式，应使用 `std::string` 存储编号，而不是整数。

## 4. 显式包含使用到的标准库头文件

使用 `std::vector` 时，应显式包含：

    #include <vector>

不要依赖其他头文件间接包含所需声明。

## 5. 遍历时避免不必要的对象复制

遍历关联式容器时：

    for (const auto& x : frequency)

相比：

    for (auto x : frequency)

可以避免复制每个键值对，并且不允许通过该引用修改元素。
