## 二、知识内容

### 1. RAII 与智能指针

RAII（Resource Acquisition Is Initialization）是一种资源管理思想：

- 在对象构造时获取资源
- 在对象析构时释放资源
- 利用对象生命周期管理资源生命周期

智能指针：

| 类型 | 所有权 | 特点 |
|---|---|---|
| unique_ptr | 独占 | 不允许复制，可以移动 |
| shared_ptr | 共享 | 通过引用计数管理资源 |
| weak_ptr | 非拥有 | 观察 shared_ptr 管理的对象，不增加引用计数 |

常用操作：
- `std::make_unique<T>()`
- `std::make_shared<T>()`
- `std::move()`
- `std::weak_ptr::expired()`
- `std::weak_ptr::lock()`
- `std::shared_ptr::use_count()`

### 2. 特殊成员函数

重点掌握：

- 默认构造函数
- 拷贝构造函数
- 移动构造函数
- 拷贝赋值运算符
- 移动赋值运算符
- 析构函数

核心区别：

| 操作 | 使用场景 |
|---|---|
| 拷贝构造 | 创建新对象时使用已有对象初始化 |
| 拷贝赋值 | 已存在的对象接收另一个对象的值 |
| 移动构造 | 创建新对象时转移资源 |
| 移动赋值 | 已存在的对象接收另一个对象的资源 |

移动语义注意事项：
- `std::move()` 本身不执行资源移动，而是将表达式转换为右值引用类型。
- 移动构造函数通常接收 `T&&`，而不是 `const T&&`。
- 被移动对象仍然有效，但其状态通常不作具体保证。

### 3. Rule of Zero / Three / Five

- Rule of Zero：优先使用具有自动资源管理能力的成员类型，不手动实现特殊成员函数。
- Rule of Three：如果需要自定义析构函数、拷贝构造或拷贝赋值，通常需要考虑另外两个。
- Rule of Five：进一步考虑移动构造和移动赋值。

如果类只包含 `std::string`、`std::vector` 等具备资源管理能力的成员，通常优先使用 Rule of Zero。

### 4. Lambda 表达式

基本形式：

`[capture](parameters) -> return_type { function_body };`

组成部分：
- capture：捕获外部变量
- parameters：参数列表
- return_type：返回类型，可以省略
- function_body：函数体

常见捕获方式：

| 写法 | 含义 |
|---|---|
| `[]` | 不捕获外部变量 |
| `[x]` | 按值捕获 x |
| `[&x]` | 按引用捕获 x |
| `[=]` | 默认按值捕获使用到的外部变量 |
| `[&]` | 默认按引用捕获使用到的外部变量 |
| `[x] mutable` | 允许修改按值捕获的内部副本 |

关键区别：
- 值捕获会在 Lambda 创建时保存变量副本。
- 引用捕获访问外部原变量。
- `mutable` 允许修改值捕获的副本，不会改变外部变量。
- 引用捕获不会延长外部变量的生命周期。

### 5. Lambda 与 STL 算法

本日练习使用了：

- `std::for_each`：遍历并执行操作
- `std::find_if`：查找第一个满足条件的元素
- `std::count_if`：统计满足条件的元素数量
- `std::sort`：根据自定义比较规则排序

工程实践中，Lambda 常用于：
- 自定义筛选条件
- 排序规则
- 回调函数
- 事件处理
- 任务执行逻辑
