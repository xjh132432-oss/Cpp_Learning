# Cpp_Learning

C++ 语言学习、现代 C++、数据结构与算法训练记录。

主要记录 C++ 基础语法、现代 C++ 特性、STL、数据结构、算法专题以及竞赛题目的学习与实践。

## Content

```text
cpp_basic
    ↓
Cpp_Modern
    ↓
Algorithm_training
    ↓
Algorithm_Coding_Practice
```

### cpp_basic

C++ 基础语法与编程练习：

- 基础语法与数据类型
- 数组 / 字符串
- 指针 / 引用
- `struct` / `class`
- 函数与面向对象基础
- `vector` 与 STL 基础
- 文件 IO
- 基础算法

### Cpp_Modern

现代 C++ 特性与标准库学习：

- 智能指针：`unique_ptr` / `shared_ptr` / `weak_ptr`
- RAII 与资源管理
- 移动语义与右值引用
- 拷贝控制与特殊成员函数
- Rule of Zero / Three / Five
- STL 容器：`vector` / `list` / `deque`
- 迭代器与迭代器失效
- 容器操作与性能特性

### Algorithm_training

算法专题训练：

- 基础算法
- 差分
- 滑动窗口
- DFS / 回溯
- 贪心
- 并查集
- 拓扑排序
- 图论
- 坐标压缩

### Algorithm_Coding_Practice

算法题与竞赛练习记录。

主要用于：

- Nowcoder
- Codeforces
- AtCoder
- ICPC / CCPC 相关训练

## Repository Purpose

本仓库主要关注 C++ 语言本身、编程能力和算法能力的持续积累。

工程化开发、CMake、Git、Linux 开发环境等内容主要放在独立的 `Cpp_Engineering` 仓库。

通过持续学习、代码实践和问题总结，逐步建立扎实的 C++ 编程基础。
